# INAGRO Figma reference

Публичная страница ручной сверки реализованных экранов ИНАГРО с соответствующими фреймами Figma и свежими полноразмерными скриншотами прома.

- `compare.html` — интерактивная карта из 12 desktop/mobile экранов.
- `manifest.json` — машиночитаемое соответствие Node ID, скриншота и URL реализации.
- `assets/` — превью экспортов Figma и страниц прома, а также мобильные PNG прома в двойной плотности (780 px по ширине) для детального увеличения.
